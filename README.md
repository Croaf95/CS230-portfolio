# CS-230: Operating Platforms Portfolio
## Software Design Document – The Gaming Room

This repository contains my completed **Software Design Document for The Gaming Room**, created for **CS-230: Operating Platforms** at Southern New Hampshire University. This artifact represents my work analyzing system requirements, evaluating operating platforms, and designing a scalable, multi-platform software solution based on client needs.

---

## Client and Software Requirements

The client for this project was **The Gaming Room**, a company seeking to expand its existing game, *Draw It or Lose It*, into a **web-based application** that could run across multiple operating systems. The client required the system to support multiple teams and players while ensuring that **only one instance of the game exists in memory at any given time**. Additional requirements included scalability, reliability, security, and compatibility across platforms such as Windows, macOS, Linux, and mobile devices.

---

## Strengths in Developing the Design Document

One area where I performed particularly well was translating the client’s business requirements into clear and organized technical design decisions. I carefully evaluated operating platforms and architectural constraints while applying object-oriented design concepts such as controlled access and instance management. My documentation clearly connects client expectations to system design choices, making the solution easier to understand and maintain.

---

## Value of the Design Process

Working through the software design document before implementation was extremely helpful. The design process required me to think through architectural decisions in advance, such as how to manage concurrency and ensure only a single game instance exists. Having this structure in place made the development process more efficient and reduced confusion during implementation. It also reinforced the importance of planning before writing code.
